## Findings considered and rejected

- O(n²) child lookup in `generateIssueFiles` (`Object.values(map).filter` per
  issue) and sequential parent fetches: n is tens of issues; not worth doing.
- Security: filenames are restricted to `[a-z0-9-]`, no secrets in repo,
  `JIRA_URL` from `.env` is the intended trust boundary. No findings.
- `npm audit`: not run (no `node_modules` at audit time). Run after 009 lands.
- `new Date(undefined).toISOString()` throws on missing `created`/`updated`:
  both fields are always requested and always present on Jira issues; low
  value, not planned.
